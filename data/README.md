# Data

Datasets are not committed to git (loan applications are personal data).
Everything in this folder except this file and `.gitkeep` is ignored.

## How to obtain the data

- **Synthetic stand-in:** run `notebooks/01_synthetic_data.ipynb` to create `data/synthetic_leads.csv`
  (same columns as the data dictionary; relationships are assumptions, not real).
  How it is generated is specified in `openspec/specs/synthetic-data-generator/`.
- **Real data:** _to be filled in once the company grants access: source, file name, and where to place it in this folder._

See [`docs/data/data-dictionary.md`](../docs/data/data-dictionary.md) for the field descriptions.
