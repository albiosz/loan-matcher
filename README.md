# loan-matcher

Deep Learning course project: predict whether a loan lead converts (is deducted) within 30 days, based on application data such as loan details, income, existing credit and employment.

The notebooks are the main result.

## Structure

| Folder | Contents |
|---|---|
| [notebooks/](notebooks/) | Numbered notebooks (the actual work) and course `examples/` |
| [data/](data/) | Datasets, not committed to git (see its README) |
| [docs/](docs/) | Project brief, data dictionary, journal, decisions, presentations, references |
| [openspec/](openspec/) | Planning artifacts for changes to this project |

Start with [docs/README.md](docs/README.md) for a map of the documentation.

## Language

All code, documents and notes are written in English.
