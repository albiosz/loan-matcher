# Agent guide: loan-matcher

Deep Learning course project (solo): predict whether a loan lead converts within 30 days. The notebooks are the main deliverable.

This repository uses OpenSpec. Everything about structure and conventions is defined there:

- `openspec/specs/`: source of truth for the repository layout and conventions (start with `project-layout`).
- `openspec/changes/`: work in flight. Read the active change before editing related files.

To change the structure or conventions, use the `/opsx:*` commands instead of editing files ad hoc, so the specs stay accurate.
